# restore-file-extension
还原文件的扩展名

## 环境
python3.6+

## 使用方法
在 table.json 中配置好扩展名与文件开头**十六进制数**的对应，
> 格式 ：`{"<十六进制数>" : "<文件扩展名(不带".")>"}`。
> 对于魔数键：`?`（匹配任意单个十六进制字符）,`*`（匹配任意长度十六进制序列）

(可选) 在 ignore.json 中指定需要跳过的文件或文件夹
> 格式 ：["<文件名或文件夹名>",...]
> 模式可以匹配文件名（如 `*.tmp`）或相对路径（如 `temp/*`、`.git/*`）

随后在脚本所在的文件夹中打开终端，执行：
```
python Batch.py [--dry-run] [-b ,<读取文件头字节数>] [-v] {<目标文件路径>|-r <目标文件夹路径>}
```
说明：
--dry-run 参数用于预览操作
--no-color 用于禁用颜色(当颜色显示异常时使用)
-v 输出更详细的信息
